🎭 O resultado que queremos alcançar

Na etapa anterior, desenhamos rostos manualmente. Agora, uma biblioteca cuidará de piscar, olhar para os lados e mudar a expressão. Nosso sensor decidirá como a planta se sente.

Prévia conceitual das expressões. A biblioteca gera animações próprias na placa; “surpreso” é uma sugestão visual para personalização, não um modo setMood() nativo.

Importante no OLED bicolor: a biblioteca desenha quadros completos e pode ocupar tanto a região amarela quanto a azul. Ajustamos a dimensão dos olhos para melhorar o enquadramento, mas as animações não têm garantia de ficar somente na área azul. No OLED branco, todos os pixels acesos são brancos.

🌱 1. Preparando a personalização

Vamos trabalhar com o mesmo hardware da Etapa 05, sem acrescentar componentes. Instale a biblioteca FluxGarage RoboEyes no Arduino IDE, além de Adafruit GFX e Adafruit SSD1306.

ComponenteESP32-C3 Super MiniFunção
Sensor capacitivo — AOUTGPIO1Leitura analógica
OLED — SDAGPIO8Dados I²C
OLED — SCLGPIO9Clock I²C
Buzzer ativo — sinalGPIO4Alertas sonoros
Sensor e OLED3V3/GNDAlimentação, conforme os módulos
Segurança elétrica: desligue o USB antes de alterar ligações. Só acione o buzzer diretamente pelo GPIO4 se a tensão e a corrente do modelo forem compatíveis; caso contrário, use acionamento por transistor validado no laboratório. Os GPIO8/9 são pinos de strapping do ESP32-C3: confirme a inicialização com o OLED conectado.

Observe a biblioteca instalada em Arquivo → Exemplos e localize os exemplos de RoboEyes. O nome exato do menu pode variar conforme a versão do Arduino IDE.

🌱 2. Dando vida aos olhinhos

Antes de integrar o sensor, teste apenas a animação. Os olhos devem piscar e fazer pequenos movimentos automáticos.

Três instruções-chave:

roboEyes.begin(128, 64, 60); inicializa o motor gráfico; roboEyes.setMood(HAPPY); escolhe a expressão; roboEyes.update(); mantém a animação fluida.

// Etapa 06 — Experimento 2: conhecendo os olhos animados.
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
#include <FluxGarage_RoboEyes.h>

Adafruit_SSD1306 display(128, 64, &Wire, -1);
RoboEyes<Adafruit_SSD1306> roboEyes(display);

void setup() {
  Wire.begin(8, 9);
  if (!display.begin(SSD1306_SWITCHCAPVCC, 0x3C)) {
    while (true) delay(1000);
  }
  roboEyes.begin(128, 64, 60);
  roboEyes.setWidth(38, 38);
  roboEyes.setHeight(30, 30);
  roboEyes.setSpacebetween(10);
  roboEyes.setBorderradius(7, 7);
  roboEyes.setAutoblinker(ON, 3, 2);
  roboEyes.setIdleMode(ON, 3, 2);
  roboEyes.setMood(HAPPY);
}

void loop() {
  roboEyes.update(); // Sem delay: anima continuamente.
}

Investigação: altere a largura de 38 para 30 e a altura de 30 para 24. Os olhos ficam maiores ou menores? Observe também o OLED branco e o bicolor.

🌱 3. Experimentando expressões

Vamos alternar automaticamente entre quatro expressões da RoboEyes: DEFAULT, HAPPY, TIRED e ANGRY. Cada uma permanece por três segundos.

Observe que millis() permite contar o tempo sem interromper roboEyes.update().

// Etapa 06 — Experimento 3: alternando expressoes.
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
#include <FluxGarage_RoboEyes.h>
Adafruit_SSD1306 display(128, 64, &Wire, -1);
RoboEyes<Adafruit_SSD1306> roboEyes(display);
unsigned long ultimaTroca = 0;
int estado = 0;
void setup() {
  Wire.begin(8, 9);
  if (!display.begin(SSD1306_SWITCHCAPVCC, 0x3C)) {
    while(true) delay(1000);
  }
  roboEyes.begin(128, 64, 60);
  roboEyes.setWidth(38,38);
  roboEyes.setHeight(30,30);
  roboEyes.setSpacebetween(10);
  roboEyes.setAutoblinker(ON,3,2);
  roboEyes.setMood(DEFAULT);
}
void loop() {
  roboEyes.update();
  if (millis() - ultimaTroca >= 3000) {
    ultimaTroca = millis();
    estado = (estado + 1) % 4;
    if      (estado == 0) roboEyes.setMood(DEFAULT);
    else if (estado == 1) roboEyes.setMood(HAPPY);
    else if (estado == 2) roboEyes.setMood(TIRED);
    else                  roboEyes.setMood(ANGRY);
  }
}
Teste orientado: identifique onde alterar os três segundos; substitua 3000 por 5000. Depois mude setMood(HAPPY) para setMood(TIRED) e observe a diferença.

🌱 5. Meu GlowUp Plant personalizado — projeto final

Agora vamos reunir os olhinhos, a porcentagem de umidade, as expressões e os alertas sonoros.

Resultado final: o OLED passa a mostrar os olhos animados; a porcentagem é apresentada no Monitor Serial, permitindo que a animação ocupe a tela. O buzzer só alerta em condições que exigem atenção, com intervalo de 30 segundos.

O programa utiliza funções próprias para leitura, expressão e som. A chamada roboEyes.update() é executada continuamente, sem delay() no loop().

// GlowUp IoT: Ciencia Delas - Expressoes da Natureza
// Etapa 06 — RoboEyes + sensor capacitivo + buzzer ativo
// IFSP - Campus Hortolandia
// ESP32-C3 Super Mini | OLED SSD1306 128x64 I2C 0x3C
// Ajuste calibracao e confirme a corrente do buzzer antes de ligar.

#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
#include <FluxGarage_RoboEyes.h>

const int PINO_SDA = 8;
const int PINO_SCL = 9;
const int PINO_SENSOR = 1;
const int PINO_BUZZER = 4;
const int VALOR_SECO = 3800;
const int VALOR_UMIDO = 1326;

// Faixas didaticas relativas: 0-20, 21-45, 46-75, 76-90, 91-100.
const unsigned long INTERVALO_LEITURA = 2000;
const unsigned long INTERVALO_BIPE = 30000;
const unsigned long DURACAO_BIPE = 90;

Adafruit_SSD1306 display(128, 64, &Wire, -1);
RoboEyes<Adafruit_SSD1306> roboEyes(display);

int leituraADC = 0;
int umidade = 0;
int estado = -1;
unsigned long ultimaLeitura = 0;
unsigned long ultimoAlerta = 0;
unsigned long inicioBipe = 0;
int bipesRestantes = 0;
bool buzzerLigado = false;
bool alertaJaEnviado = false;

void iniciarBipes(int quantidade) {
  bipesRestantes = quantidade;
  buzzerLigado = false;
  digitalWrite(PINO_BUZZER, LOW);
}

void atualizarSom(unsigned long agora) {
  // Um bipe por vez, sem delay() para nao congelar os olhos.
  if (buzzerLigado && agora - inicioBipe >= DURACAO_BIPE) {
    digitalWrite(PINO_BUZZER, LOW);
    buzzerLigado = false;
    inicioBipe = agora;
    bipesRestantes--;
  }
  if (!buzzerLigado && bipesRestantes > 0 && agora - inicioBipe >= 160) {
    digitalWrite(PINO_BUZZER, HIGH);
    buzzerLigado = true;
    inicioBipe = agora;
  }
}

void aplicarExpressao(int novoEstado) {
  // Limpa efeitos anteriores antes de aplicar outra expressao.
  roboEyes.setHFlicker(OFF);
  roboEyes.setVFlicker(OFF);
  roboEyes.setSweat(OFF);
  roboEyes.setCuriosity(OFF);
  roboEyes.setPosition(DEFAULT);

  switch (novoEstado) {
    case 0: // Critico seco
      roboEyes.setMood(TIRED);
      roboEyes.setPosition(S);
      break;
    case 1: // Com sede
      roboEyes.setMood(ANGRY);
      break;
    case 2: // Perfeito
      roboEyes.setMood(HAPPY);
      break;
    case 3: // Excesso de agua
      roboEyes.setMood(TIRED);
      roboEyes.setSweat(ON);
      break;
    case 4: // Critico de excesso de agua
      roboEyes.setMood(ANGRY);
      roboEyes.setSweat(ON);
      break;
  }
}

int identificarEstado(int porcentagem) {
  if (porcentagem <= 20) return 0;
  if (porcentagem <= 45) return 1;
  if (porcentagem <= 75) return 2;
  if (porcentagem <= 90) return 3;
  return 4;
}

void atualizarMedicao(unsigned long agora) {
  leituraADC = analogRead(PINO_SENSOR);
  if (VALOR_SECO == VALOR_UMIDO) return;
  umidade = map(leituraADC, VALOR_SECO, VALOR_UMIDO, 0, 100);
  umidade = constrain(umidade, 0, 100);
  int novoEstado = identificarEstado(umidade);

  Serial.print("ADC: "); Serial.print(leituraADC);
  Serial.print(" | Umidade relativa: "); Serial.print(umidade);
  Serial.print("% | Estado: "); Serial.println(novoEstado);

  if (novoEstado != estado) {
    estado = novoEstado;
    aplicarExpressao(estado);
    if (estado == 0 || estado == 1 || estado == 4) {
      iniciarBipes(estado == 4 ? 3 : 2);
      ultimoAlerta = agora;
      alertaJaEnviado = true;
    } else {
      iniciarBipes(0);
      alertaJaEnviado = false;
    }
  } else if ((estado == 0 || estado == 1 || estado == 4) &&
             (!alertaJaEnviado || agora - ultimoAlerta >= INTERVALO_BIPE)) {
    iniciarBipes(estado == 4 ? 3 : 2);
    ultimoAlerta = agora;
    alertaJaEnviado = true;
  }
}

void setup() {
  Serial.begin(115200);
  analogReadResolution(12);
  pinMode(PINO_BUZZER, OUTPUT);
  digitalWrite(PINO_BUZZER, LOW);
  Wire.begin(PINO_SDA, PINO_SCL);

  if (!display.begin(SSD1306_SWITCHCAPVCC, 0x3C)) {
    Serial.println("OLED nao encontrado!");
    while (true) delay(1000);
  }
  roboEyes.begin(128, 64, 60);
  // Olhos compactos: ocupam principalmente a regiao azul no bicolor.
  // As animacoes (piscar/suor) podem usar outras linhas do visor.
  roboEyes.setWidth(38, 38);
  roboEyes.setHeight(30, 30);
  roboEyes.setBorderradius(7, 7);
  roboEyes.setSpacebetween(10);
  roboEyes.setAutoblinker(ON, 3, 2);
  roboEyes.setIdleMode(ON, 3, 2);
  roboEyes.setMood(DEFAULT);

  // Primeira medida imediata para escolher a expressao.
  atualizarMedicao(millis());
  ultimaLeitura = millis();
}

void loop() {
  unsigned long agora = millis();
  roboEyes.update(); // Atualizar continuamente: sem delay() no loop.
  atualizarSom(agora);
  if (agora - ultimaLeitura >= INTERVALO_LEITURA) {
    ultimaLeitura = agora;
    atualizarMedicao(agora);
  }
}
Antes de gravar: confira novamente os valores de calibração e o tipo de buzzer. O programa não usa Wi-Fi, sensor de distância ou Google Sheets. Essas funções pertencem a possíveis expansões futuras e não são necessárias para esta etapa.

Sequência de testes

  1. Carregue o programa e confirme que os olhos piscam.
  2. Abra o Monitor Serial em 115200 baud.
  3. Teste o sensor em condição mais seca: observe os olhos e o alerta.
  4. Aumente a umidade e verifique a mudança para uma expressão feliz.
  5. Observe o comportamento com leituras elevadas, sem mergulhar componentes não impermeáveis.
  6. Verifique se os alertas sonoros não se repetem continuamente.
